About the Model

🤖 Algorithm

K-Nearest Neighbors is a simple yet effective classification algorithm that assigns a data point to the class of its k nearest neighbors.

📈 Dataset

The Iris dataset contains 150 samples of iris flowers with 4 features and 3 species: Setosa, Versicolor, and Virginica.
